# KTC コーポレートサイト リニューアル提案

株式会社国際テクノロジーセンター（KTC）の公式サイト掲載情報をもとに制作した、公式サイトとは独立した静的HTML/CSS/JavaScriptの提案プレビューです。GitHub Pagesにて確認用に公開し、`noindex,nofollow` と `robots.txt`（全体 Disallow）を設定しています。

確認用URL：https://suzuki-commits.github.io/ktcc-renewal-preview/

## ファイル

- `index.html` — ページ本体
- `styles.css` — レスポンシブデザイン
- `app.js` — モバイルメニュー開閉
- `assets/img/logo.png` — 公式ロゴ（ヘッダー）
- `assets/img/foot_logo.png` — 公式ロゴ（フッター）

`assets` 内の画像は公式サイト掲載の素材を使用しています。
